# 문제 해결 사례 — AI 토론장

> 각 사례는 상황 → 고른 것 → 이유 → 결과 → 배운 점. "왜 그렇게 했나"가 핵심이다.

## 사례 1. 원본과 한 줄씩 대조하기

- **상황**: ChatGPT와 1차 구현을 끝낸 뒤, 교수님 원본에서 무엇이 바뀌었는지 확인해야 했다.
- **고른 것**: 원본 코드와 나란히 놓고 함수별로 비교했다.
- **결과**: `debate_turn()`은 동일했다. 그런데 프롬프트를 함수로 바꾸면서 규칙 3의 "**존댓말로**"가 "{말투} 말투로"로 바뀌어 빠져 있었다. "{말투} 말투의 존댓말로"로 고쳐 두 조건을 모두 살렸다.
- **배운 점**: 일반화(상수 → 함수)할 때 원래 조건이 조용히 사라질 수 있다. 바꾼 부분일수록 원본과 대조한다.

## 사례 2. API 키 없이 먼저 검증하고, 마지막은 실제로 돌리기

- **상황**: 실제 API로 테스트를 반복하면 무료 사용량이 금방 줄어든다.
- **고른 것**: Gemini를 흉내 내는 가짜 서버를 띄워 앱을 실행했다. 호출 순서와 횟수, 두 봇의 기록이 섞이지 않는지, 오류가 나면 어떻게 되는지를 확인했다.
- **결과**: 1·3·5라운드에서 요청이 6·10·14회였고, 기록 분리는 정상이었다. 429(사용량 초과)나 깨진 JSON이 와도 앱이 멈추지 않고 그때까지의 발언이 남았다. 단, 실제 서버가 기록 형식을 받아 주는지는 가짜 서버로 알 수 없어서 마지막에 실제 실행 1회로 확인했다.
- **배운 점**: 가짜 서버는 "내 코드"를 검증하고, 실제 실행은 "상대 서버와의 약속"을 검증한다. 둘은 서로 대신할 수 없다.

## 사례 3. 요청 제한을 숫자로 따지기

- **상황**: 교수님 자료는 분당 15회 제한을 고려하라고 안내했다.
- **고른 것**: 요청 수를 `1 + 2R + 3`으로 계산하고 사이드바에 "예상 API 요청"으로 보여 줬다.
- **결과**: 5라운드(14회)는 한 번은 들어가지만, 3라운드(10회)도 1분 안에 두 번 돌리면 넘는다. 그래서 실제 실행은 한 번에 한 판씩만 했다. 재시도 설정은 서버 오류(500·503)만 다시 보내고 429는 바로 멈추게 되어 있어, 한도에 걸려도 요청이 더 쌓이지 않는다.
- **배운 점**: "한 번 실행"이 안전해도 "연속 실행"은 다르다. 제한은 사용 방식까지 같이 봐야 한다.

## 사례 4. 실제로 돌려 봐야 보이는 문제

- **상황**: 실제 토론 결과를 읽어 보니 코드 테스트에서는 안 보이던 점이 있었다.
- **발견**:
  - 심사위원에게 토론 기록만 주고 **주제는 주지 않았다** → 주제에서 벗어난 주장을 평가할 수 없음
  - 찬성봇 첫 발언이 4문장 → "3문장 이내" 규칙을 어김
  - "차분한 교수"와 "열정적인 대학생"의 말투 차이가 거의 없음
  - 사이드바에서 긴 주제가 잘려 보이고, 결과 화면에는 주제가 없음
- **고른 것**: 범위를 작게 잡아 3가지만 고쳤다. 심사위원 입력에 주제를 넣고, 존댓말 조건을 복원하고(사례 1), 결과 위에 실제 토론한 주제를 표시했다. 문장 수·말투는 프롬프트만으로는 보장되지 않는 문제라 남겨 두었다.
- **결과**: 수정한 코드는 최종본(`dd47cc2`)에 들어 있다. 수정 후의 실제 실행 결과는 따로 남기지 않았다.
- **배운 점**: LLM에 준 규칙은 "지시"일 뿐 보장이 아니다. 꼭 지켜야 하는 것은 코드로 확인해야 한다.

## 사례 5. 배포에서 생긴 문제는 로그부터

- **상황 1**: 중간 배포 하나가 실패했다. Streamlit 로그에 주제 문자열의 둥근 따옴표(`“`) 때문에 `SyntaxError`가 남아 있었다 → 일반 따옴표로 고친 다음 커밋부터 정상 배포됐다.
- **상황 2**: PC Chrome에서는 열리는데 카카오톡 링크로 열면 로딩에서 멈췄다. 앱 코드가 실행되기 전 단계에서 멈춰서, 코드보다 앱 안 브라우저 환경 문제로 판단했다 → 받는 사람에게 PC Chrome 접속을 안내하는 것이 안전하다.
- **배운 점**: 문서나 메신저에서 복사한 코드는 따옴표부터 의심한다. "내 컴퓨터에서 된다"와 "받는 사람이 열 수 있다"는 따로 확인한다.
